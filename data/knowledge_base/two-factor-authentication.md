# Two-Factor Authentication

NovaDesk supports two-factor authentication using authenticator applications.

Users can enable two-factor authentication from:

Settings > Security > Two-Factor Authentication

When two-factor authentication is enabled, NovaDesk provides recovery codes.

Recovery codes should be stored securely because they can be used if the authenticator device becomes unavailable.

If a user loses both the authenticator device and recovery codes, NovaDesk Support must verify account ownership before two-factor authentication can be reset.

Support cannot provide or recover the user's original authentication codes.
